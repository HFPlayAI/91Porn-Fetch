## 软件简介

91Fetch 是专用于 **91porn 网站**的视频浏览、采集和批量下载工具，提供中文本地网页界面，适合在 Windows 电脑上直接运行。软件可直接浏览最新发布、当前最热、加精推荐、每日排行、本月最热、最多收藏、最多讨论、高清视频和原创视频分类，也支持指定作者主页与自定义列表 URL。

列表会显示视频标题、封面、作者、时长、播放量和 viewkey。勾选单个视频或全选当前页即可加入下载队列，添加后仍可继续浏览和选择。下载前会解析真实 `.m3u8` 或 `.mp4` 地址，并通过 yt-dlp 实现 HLS 分片并发、失败重试和断点续传。

本仓库基于上游项目：[https://github.com/ChaosTechDev/91Fetch](https://github.com/ChaosTechDev/91Fetch)二次修改

## 主要功能

- 91porn 九类视频目录、作者主页与自定义 URL 浏览
- 全站搜索：按标题、用户名搜索整站内容，也可直接粘贴视频 ID 或视频页地址定位单个视频
- 列表结果本机缓存（首页 5 分钟、翻页 30 分钟）并自动预取下一页，滚动到底无缝加载，切分类不再重复请求站点
- 标题、封面、作者、时长、播放量和 viewkey 展示
- 单选、全选和批量加入下载，下载队列支持继续追加
- `.m3u8` / `.mp4` 解析，HLS 分片并发、重试和断点续传
- 下载管理按全部、未完成、已完成筛选，支持选择、重试和删除任务
- 「下载全部未完成」只续传下载管理里列出的未完成任务（按钮上标着数量、为 0 时置灰），已删除的任务和从没下载过的采集结果不会被重新排队
- 下载任务、进度和完成状态持久化，重新启动后自动续排未完成任务
- 扫描下载目录识别本地文件，跨分类显示“已下载”并按 viewkey 去重
- 日间/夜间主题、列表过渡动画和局部进度刷新
- 设置中心统一管理下载目录、归档方式、并发数和界面刷新间隔
- 自定义代理：支持 `127.0.0.1:7897` 这类 HTTP 代理，采集、解析、登录、下载以及缩略图抓取全部走代理，并可在设置里一键测试连通性
- 站点列表：可自行添加 91PORN 的其他站点，保存后从顶栏或设置里直接切换当前生效站点，切站点后已采集条目自动对齐新域名

## Windows 一键启动

需要 Windows 10/11 和 Python 3.11 或更高版本。下载 Release 压缩包并解压后，双击 `启动.cmd`。首次运行会自动创建 `.venv`、安装依赖、生成 `site.json`、启动本地服务并打开网页。

默认数据保存在 `downloads/`，视频保存在 `downloads/videos/`。可在网页设置中心修改视频目录和归档方式。

程序只在本机提供网页服务，默认监听 `127.0.0.1:8765`；下载任务、目录设置和已下载识别记录保存在本地数据目录中。升级程序时请保留 `downloads/`，其中包含任务状态和本地索引。

手动启动：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
Copy-Item site.example.json site.json
.\.venv\Scripts\python.exe -m viewkey_batch.web
```

默认地址为 `http://127.0.0.1:8765`；端口被占用时会自动选择后续可用端口。

## 站点配置与请求限制

`启动.cmd` 首次运行时会从 `site.example.json` 生成 `site.json`。可在其中调整分类入口、请求间隔、随机抖动、重试次数和退避策略；`search_url` 和 `video_url` 分别是全站搜索页和单条视频页的地址模板（`{query}`、`{viewkey}` 占位），站点改版时改这两行即可。

程序默认限制请求频率，遇到 `429` / `5xx` 会自动退避；识别到验证页面时会停止当前任务。每次访问分类会先建立站点会话并添加防缓存参数，避免不同分类返回相同旧数据。媒体下载前会重新解析视频页，以刷新可能过期的 CDN 地址。

## 搜索、缓存与翻页

顶栏搜索框是**全站搜索**，请求站点的 `search_result.php`，不再只是过滤当前页：

- 输入两个及以上字符会停顿 450ms 后自动搜索，单字需按回车；`Esc` 或输入框右侧的 × 退出搜索回到分类浏览
- 直接粘贴 16 位 viewkey 或完整的 `view_video.php?viewkey=...` 地址，会打开对应视频页并返回该视频，标题里的站名后缀会被去掉
- 结果按标题、作者和视频 ID 展示，可勾选后直接下载

翻页不再点「上一页 / 下一页」：滚动到底部自动加载下一页（`IntersectionObserver`），底部显示「已加载 N 条 · 第 X 页 · 缓存 X 分钟前」。当前页返回后，服务端会串行预取下一页，滚到底时几乎立刻出内容。

列表缓存存放在 `downloads/cache/listings/`，键里包含站点域名，切站不会串数据；`刷新` 按钮和「重新尝试采集」会带上 `refresh=1` 强制回源，设置中心的「界面刷新」可以查看缓存占用并一键清理。

## 站点列表与代理

设置中心新增「站点列表」和「网络代理」两栏：

- **站点列表**：在输入框填写站点域名（如 `https://a.example.com`，也可只写域名），点击「添加站点」后保存到 `downloads/sites.json`。列表里选中哪一项，`site.json` 的 `base_url` 就会切到哪个站点，其它解析规则保持不变。顶栏的站点按钮可以在不进入设置页的情况下直接切换。
- **网络代理**：填写 `127.0.0.1:7897` 这类地址即启用代理，留空则使用系统代理或直连。支持 `http://`、`https://` 前缀，SOCKS5 需要额外安装 `socksio`。设置页的「测试连通性」会用当前站点首页做一次真实请求并返回耗时。视频缩略图也由后端经该代理抓取并缓存到 `downloads/thumbs`，不依赖浏览器自身的网络设置。

切换站点时会自动把已保存 Cookie 的域名迁移到新站点，下载时记录的旧域名列表页和视频页地址也会按新域名重新拼装。

## 命令行

```powershell
91fetch crawl --category latest --max-pages 10
91fetch crawl --author AUTHOR_ID
91fetch download --workers 2 --fragments 4
91fetch run --category featured --workers 2 --fragments 4
```

网页界面是默认使用方式；命令行适合一次性脚本任务。
